# Hi, I'm Jaskeerat Singh Saluja

I build reliable backend and data systems at the intersection of **distributed workflows, developer tooling, and applied AI**. I study **Mathematics and Computing at IIT Delhi**.

I enjoy turning ambiguous operational problems into small, testable systems—especially where failures arrive late, repeat, or disagree with local state.

## Selected work

- **[RelayGuard](https://github.com/salujajaskeerat/relayguard)** — A lightweight reliability layer for webhook-driven integrations. It provides durable ingestion, duplicate protection, bounded retries, atomic worker leases, and provider-state reconciliation using embedded SQLite.
- **[Branchline](https://github.com/salujajaskeerat/branchline)** — Semantic change review for versioned metric trees. It validates metric definitions, replays changes against data, and explains downstream business impact before merge.
- **[Accord Project](https://github.com/accordproject)** — Contributing to open-source business schema and contract tooling.
- **[ReLU-NMD](https://github.com/salujajaskeerat/relu-nmd)** — Research code for non-linear matrix decomposition.
